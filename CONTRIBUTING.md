# Contributing

Obrigado por querer contribuir! Seguem algumas orientações rápidas:

- Abra uma issue antes de iniciar trabalho substancial.
- Faça um fork, crie uma branch com nome descritivo e envie um PR com descrição e passos para testar.
- Execute lint e testes localmente antes de abrir PR:

```bash
npm run lint
npm test
```

- Siga os padrões de estilo (Prettier + ESLint).
